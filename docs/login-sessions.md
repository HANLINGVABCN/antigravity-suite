# 登录存档与退出配置

## 每次登录保存一个配置

部署时已有的登录只提取一次，普通卡片名为“默认配置-机器名”。部署后每次**成功重新登录**都新增一个配置，包括同一个邮箱的再次登录。配置默认命名为“邮箱 · 登录 N”，创建后可以改名或绑定节点，ID 始终不变。

程序同时记录登录操作编号与凭据哈希。不能仅凭整个文件的哈希变化判断新登录：正常续期也会改变文件，否则配置列表会不断增长。兼容客户端的登录开始和成功回调用于区分新登录，哈希用于识别重复读取和当前会话的凭据更新。

| 操作 | 配置列表 |
|---|---|
| 再次成功登录同一邮箱 | 新建一个配置，旧配置保留 |
| 成功登录不同邮箱 | 新建一个配置，旧配置保留 |
| 当前会话的访问令牌续期 | 更新当前配置的凭据，不新增 |
| 从面板切换到已有配置 | 载入原 ID，不新增 |
| 点击“停止 IDE”或重启服务 | 保存当前配置，不计作重新登录 |
| 登录取消或失败 | 不创建成功登录的存档 |

后台每 3 秒检查当前工作环境，普通变化需连续稳定读到后才处理。成功回调会立即尝试保存；如果文件仍在写入，后续扫描再重试。旧账号卡片不会直接改成另一个账号，同邮箱的旧会话也不会被新登录覆盖。

## 桌面端与 CLI 共用登录

v0.9.7 支持同一 Linux 用户的官方 `agy` 文件存储回退。请先自行安装 CLI；后台从该用户的 `~/.local/bin/agy` 或服务 PATH 识别兼容二进制。Windows 官方桌面端和 CLI 通过系统密钥环共用登录，本项目不会读取或修改 Windows 密钥环。

Linux 无 D-Bus 的容器中，桌面使用 `~/.gemini/jetski-standalone-oauth-token`，CLI 实际读取 `~/.gemini/antigravity-cli/antigravity-oauth-token`。后台把 CLI 入口链接到桌面当前工作凭据，CLI 正常续期直接更新同一文件，面板切换配置后新启动的 CLI 读取所选账号。只共享登录，不复制、移动或改写两者的聊天目录。

### SSH 运行 CLI 与共用代理

后台会可恢复地接管原用户 `~/.local/bin/agy` 启动入口，官方二进制保留为同目录的 `agy.suite-real`。直接运行 `agy`，自动读取当前配置并使用桌面同一个 loopback HTTP 代理桥；HTTP、HTTPS、SOCKS4/4a、SOCKS5/5h 节点由这个桥统一处理。调用者原先的代理环境会被清除或替换，避免 CLI 和桌面意外使用不同出口。

绑定节点时，启动前通过代理桥检查 Google 连接，失败时明确提示可能原因并拒绝启动，不回退直连。未绑定节点时不额外增加应用层代理，系统已有的 mihomo TUN 或其他全局路由仍可能接管流量，实际出口需以检测结果为准。停止桌面程序后代理桥仍保留，CLI 可以继续运行；后台需保持运行，重启期间新的 CLI 启动可能暂时被拒绝，恢复后重试即可。已有代理桥端口在后台重启后复用。

启动器使用反重力原运行用户，root 调用时也降到该用户，工作目录必须对该用户可访问。状态文件位于原用户 `~/.local/share/antigravity-suite/cli-runtime.json`，权限 600，只包含本机代理桥地址和运行身份，不保存节点密码。执行卸载脚本会停止对应 CLI 并恢复原官方启动入口；若入口被其他操作修改，拒绝覆盖并保留现状。

本项目当前网址仍反代桌面端 Web 前端。官方 CLI Remote Control 使用 Google 的网页前端与中继；直接访问那个官方网页时，Google 可看到浏览器出口 IP，服务器上的共用代理不会自动代理你本地浏览器。

已有 CLI 凭据会先备份到 `data/cli-credential-backups`，文件权限 600。同一授权保留较新的令牌；桌面未登录而 CLI 已登录时，可按现有规则提取为配置。两者已有不同授权时均保留，并显示需从面板切换所需配置的提示，避免悄悄覆盖另一账号。只有正常令牌续期时不创建新卡片。

切换或退出配置时，后台自动关闭同一用户、同一运行目录中正在使用这份登录的 CLI，再更换凭据，避免旧会话续期覆盖新账号。关闭检查以原运行用户执行，兼容 root 没有进程读取能力的容器；先发送正常结束信号，超过 5 秒才结束仍匹配的进程。终端窗口及其他运行目录的 CLI 保留，后续在原终端重新运行 `agy` 即可使用所选账号。如果其他管理器不断重新启动 CLI，后台显示可能原因并暂停更换。CLI 自己的 `/logout` 不受图形客户端退出保护拦截，可能影响共用授权，建议使用面板“退出配置”。本体或 CLI 未来改变凭据格式、文件名或写入方式时需重新验证兼容性。

可在服务器终端运行 `agy models` 验证账号是否能够读取模型列表；这项检查不会发送 AI 对话，但仍会连接 Google 验证或刷新授权。能读取凭据不等于服务端保证授权永久有效。

## 退出配置

“退出配置”只放在当前选中的配置卡片及桌面／网页悬浮面板对应的配置行内，未选中的卡片不显示，顶部不再显示。它依次停止当前引擎，保存登录存档，备份并移除**当前工作环境**的登录文件，然后重新打开反重力登录界面。已保存的配置和共享聊天记录保留，不向 Google 发送撤销授权请求。

退出后网页显示未登录状态，可点击“进入登录界面”完成新登录，也可选旧配置“切换并启动”，等待完成后“进入”。管理服务重启后保持等待登录，不自动把默认账号恢复回来。“停止 IDE”仅停止并保存；“退出后台”仅退出管理网页。

顶部运行按钮显示“停止反重力”，停止后变为“启动反重力”，启动过程中禁用并显示“启动中…”。停止的是登录界面时，再启动仍打开未登录界面；不会自动恢复旧账号。“退出配置”在当前配置卡片内，负责回到未登录状态。

清理后会调用原生只读接口确认当前环境没有登录 Token。无法确认时退出显示异常及可能原因，并尝试恢复退出前的状态；原存档和退出备份保留。工作目录与存档目录分开，没有外部原配置时使用 `data/login-environment/home`，不会通过删除存档 HOME 来退出。

## 原生退出保护

兼容的 Linux Electron 客户端会安装可恢复的本体保护。升级时先停止被接管的实例、保存当前配置，再更新保护并重启。安装路径需要写权限；不兼容入口或未验证的客户端不会被误报为保护已完整生效。网页会显示“已安装，等待客户端验证”或“桌面退出保护已验证”。

原生“退出登录”在按钮处理和认证方法改变状态之前被拦截，弹窗提示：

> 退出登录可能使已保存的登录凭据失效。请返回配置面板，使用“退出配置”。

点击提示的“确定”仅关闭提示，保持当前登录、页面和应用运行，不自动跳转或打开面板。需要退出时，自行返回配置面板，在当前选中卡片里点击“退出配置”。不能只拒绝退出 RPC：原生代码在请求失败后的清理分支也可能改变本地登录界面，因此本版替换整个已验证的退出方法，并在原生账号按钮点击前停止原处理。

升级后刷新网页会加载带版本参数的原生脚本，避免旧缓存只执行请求层拦截。卡片退出请求携带配置 ID，后台核对它仍是当前配置，防止旧页面误退出后来选中的账号。

网页网关和原生请求层也拒绝 `AuthLogout`，避免绕过按钮直接提交该接口。其他插件和管理后台自己的登出不在拦截范围。原生弹窗使用客户端页面实现，避免受限桌面容器的 GTK 系统弹窗错误。

原本体资源备份保存到 `data/desktop-guard-backups`，不会提交到公开仓库。仅本体更新、手工修改或未来版本差异可能使保护不再兼容；遇到“等待验证”或错误时请通过面板退出，并保留备份排查。

## 恢复原生退出与卸载

卸载本体前会恢复原资源，再将本体移到备份。卸载管理服务的脚本也会恢复保护。容器手动卸载时，先停止管理服务和使用同一本体的反重力实例，再运行：

```bash
ANTIGRAVITY_SUITE_DATA=/你的私有数据目录 \
  /你的项目目录/.venv/bin/python /你的项目目录/desktop_guard.py --restore
```

恢复前核对当前资源和原备份的哈希；如果本体已发生其他修改，会拒绝覆盖。需要保留原备份并按实际版本处理，不能直接拿旧资源替换任意新版客户端。

## 使用边界

多个登录存档可能来自同一份 Google 授权，保存为不同配置不等于 Google 为每个文件提供独立授权，也不保证永远有效。外部撤销授权、修改账号安全设置或服务端失效仍可能影响多个存档，检测结果才反映当前可用性。

桌面控制连接只监听本机，使用每次管理服务启动生成的能力令牌；仅允许查看精简状态、切换、重启、退出配置和记录登录。它不分享后台密码、验证器或管理员会话，也不提供导出凭据、编辑任意文件或执行任意命令的接口。系统用户之间的权限隔离及网络出口限制仍见 [隐私说明](privacy.md)。
