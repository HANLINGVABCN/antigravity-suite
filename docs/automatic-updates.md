# 网页自动更新

顶部点击 **更新项目**，打开后自动检查本项目 GitHub 最新正式版，也可点击 **检查更新**。发现新版本时点击 **自动更新**，即可在网页完成升级。

只更新管理后台，不重新安装反重力本体。页面显示下载、校验、准备环境、备份、替换、重启和完成状态。更新进程独立于管理服务，服务重启后仍继续工作；浏览器暂时无法连接时自动等待，完成后刷新页面。关闭窗口不会取消更新。

## 数据保留

开始替换前，管理服务先停止并保存正在运行的反重力状态，再备份私有数据和原源码。更新保留当前管理员密码、验证器、账号 ID、节点 ID、代理绑定、默认账号、端口和聊天记录。

新版依赖先在独立环境安装，成功后才停止原服务。附件和版本检查失败不会修改原服务；新版启动检查失败时恢复原源码和 Python 环境，并恢复停止时的账号配置。备份与日志保存在私有数据目录的 `updates/<任务ID>/backup` 和 `worker.log`，其中包含凭据，应私有保管。

更新期间暂停修改配置、本体操作、导入及启动等管理操作，状态页面仍可读取。切换或本体操作还未结束时不开始更新，完成后重试即可。

## 支持的部署

- systemd：安装器登记本服务名称；独立更新进程通过 transient service 运行，因此不会随管理服务关闭而退出。
- Supervisor / s6：从当前服务的 Supervisor 环境识别它的本地控制 socket 和程序名称，只停止、启动这一个程序。实验桌面容器使用此方式。
- 手动启动或未识别的服务管理器：检查更新仍可用，自动更新按钮显示不可用原因。需要按部署说明更新，或配置为受支持的监管方式；网页不接受自定义 shell 命令。

服务用户需要源码和私有数据目录的写权限、可访问的 GitHub HTTPS 网络和至少 768MB 可用磁盘空间。已有 Python 环境、源码和备份保留在更新任务目录，长期使用需自行维护备份占用。

## 来源和检查

只接受 `HANLINGVABCN/antigravity-suite` 的 GitHub 正式发布及固定名称源码 ZIP。下载后核对随附 SHA256、GitHub 附件摘要（存在时）、包内版本及必要文件；拒绝目录穿越、链接、私有配置、本体和未知可执行文件。浏览器只请求自己的后台，由服务器请求 GitHub。

GitHub 暂时不可用或限速时显示可能原因并允许稍后重试。若服务重启后无法访问，先核对原端口和服务状态；自动恢复未完成时，依据私有备份和日志恢复。不要把私有日志、配置或备份上传到公开 issue。
