# 隐私、账号环境与共享聊天记录

## 浏览器请求边界

本套件默认向管理页、原生 IDE 页面及相关响应添加 Content Security Policy，限制跨域资源、fetch、beacon、图片、iframe、字体和 WebSocket。还会移除外部预连接提示、客户端 IP 转发头，阻止外部 HTTP 重定向，在原生页面中限制 WebRTC。

浏览器的 Cookie、localStorage、sessionStorage 和 IndexedDB 按配置区分。访问入口应使用专属域名，避免与其他应用同源；不建议在同一浏览器同时使用多个配置的旧 IDE 页面。

这不是整台设备的网络隔离。其他网站、浏览器扩展、用户主动离开的页面、第三方程序以及未被浏览器策略覆盖的导航不由本套件控制。Google 授权从配置大厅单独发起，是允许浏览器直连的例外。

官方网页语音输入允许当前网站请求麦克风（`microphone=(self)`），浏览器仍需用户授权；摄像头和屏幕共享继续禁止。语音经官方页面的本地服务接口处理，外部连接策略不会因此放开。HTTPS 页面需要实际可用的浏览器麦克风；虚拟桌面里的官方客户端则需要容器音频服务和远程桌面的麦克风输入，不能自动使用访问电脑的麦克风。

外部字体、预览、反馈、插件集成或语音功能可能因此不可用。不要把“受控测试中接收端收到 0 个请求”理解成对所有浏览器和未来上游版本的绝对保证。

受保护的原生主脚本使用 gzip 和 `private, no-cache, must-revalidate`，浏览器可保留并在每次访问后台鉴权后重新校验；共享反代不能缓存这份响应。脚本内容、运行实例、当前配置或保护代码发生变化时重建并返回新校验值。首页、登录信息和配置接口仍按原策略不缓存，未登录请求不能凭 ETag 获取脚本或 304 响应。

原生状态和聊天列表等六种已识别的本地长期订阅通过本项目鉴权 WebSocket 传输。接口只允许固定的本机订阅方法，使用当前运行端口和账号，不接收任意目的地址；管理员 Cookie、客户端 IP 转发头和任意命令不能通过订阅消息传给原生服务。连接结束或切换当前环境时会取消上游订阅。它改变本地数据更新的传输方式，不新增 Google 登录授权或模型调用。

## 服务器出口

浏览器通过反代访问套件时，后端模型请求通常由 VPS 发出。未绑定面板代理时，套件不额外设置应用层代理，实际出口仍受系统路由、mihomo TUN 或其他全局隧道影响；不能只凭“未绑定节点”就断言流量直接使用 VPS 网卡出口。绑定代理时套件通过 loopback HTTP 桥向引擎提供节点。启动前会检查节点，失败时阻止启动，不自动改走直连。

环境变量和 Chromium 参数不能强制所有扩展或子进程使用代理。如果要求服务器**任何程序**都不能直连，需要另外使用网络命名空间、防火墙或容器出站控制并进行网络层验证。本仓库没有实现这种网络层保证。

v0.9.7 接管兼容 Linux CLI 的 `agy` 入口，向 CLI 提供与桌面相同的本机代理桥，并替换原有 HTTP(S)/ALL_PROXY 和 NO_PROXY 环境。绑定节点时，启动检查失败不回退直连；未绑定节点则使用服务器直接出口。这个保证覆盖遵守这些代理设置的 CLI 请求，不等于为 CLI 执行的任意第三方命令提供网络层隔离。

CLI 官方 Remote Control 的网页入口属于 Google，需要浏览器登录同一账号；直接访问时浏览器与 Google 通信，服务器代理不会自动覆盖这部分流量。自建域名目前仍转发桌面端 Web 前端，CLI 共用登录与代理不改变它。

## 账号隔离

每个登录配置拥有固定的独立凭据存档，当前主引擎使用固定的原运行目录，没有原目录时使用固定内部环境。切换只保存和载入凭据及代理，软件设置、工作目录和聊天库保持共用。检测其他配置时使用临时隔离目录，不改当前登录或聊天。切换任务串行执行。

这些目录隔离用于防止意外串号，不是不同系统用户之间的权限隔离。引擎仍使用相同系统用户及二进制。项目适合单管理员管理自己的账号，不用于互不信任的多租户。

## 所有聊天记录共享

所有配置读取同一份本地对话库：

| 路径（相对原运行 HOME） | 内容 |
|---|---|
| .gemini/antigravity/conversations/ | 对话正文 |
| .gemini/antigravity/brain/ | 过程文件和工件 |
| .gemini/antigravity/conversation_summaries.db | 列表和搜索索引 |

聊天库位置记录在数据目录的 history-location.json。旧部署已有共享链接时沿用其实际库位置，不改变目录指向；账号只保存自己的凭据。正常切换、停止或退出不复制、迁移或删除聊天。导出勾选聊天才附带全部记录，导入勾选聊天才执行合并或覆盖。覆盖将替换所有配置共用的聊天库，旧记录不会因换账号恢复。

共享本地记录不自动将全部对话发送给另一个账号。用当前账号继续历史对话时，模型可能收到该请求实际携带的历史上下文。

目录位置、索引结构和浏览器行为依赖 Antigravity 版本。项目验证过 2.24.0/2.29.0 的相关路径；升级上游前先备份并检查兼容性。

账号风控、身份指纹、地区许可和服务资格仍由 Google 判断。本项目不承诺免风控，也不伪造账号或地区资格。


## 已有运行配置与两个入口

发现唯一可接管原配置时，桌面和网页使用同一份当前运行配置，切换账号会先保存独立存档，再载入所选账号。当前使用者可访问该账号的运行数据，因此此模式不提供桌面用户之间的隔离；无原配置时使用内部工作 HOME。账号存档的固定身份、节点绑定和共享聊天库保留。详见 [原配置说明](existing-installations.md) 与 [登录存档](login-sessions.md)。
